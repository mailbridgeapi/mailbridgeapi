# Contributing

Documentation fixes and safe example improvements are welcome.

1. Open an issue describing the problem.
2. Keep all examples in English and use placeholder addresses and keys.
3. Never commit credentials, mailbox content, production logs, or customer data.
4. Keep examples dependency-light and check errors explicitly.
5. Update `openapi.json` when a public endpoint contract changes.

For product support or account questions, use <https://dashboard.mailbridgeapi.com/support/>.
